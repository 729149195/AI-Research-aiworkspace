## AI Workspace · 论文助手

**当前论文：尚未读取项目状态**
可以新建论文，或打开已经写过的论文。

| 选择 | 功能 |
|---|---|
| 1 | 新建论文 |
| 2 | 继续写／修改论文 |
| 3 | 找文献／整理证据 |
| 4 | 讨论想法／检查逻辑 |
| 5 | 方法、数据与图表 |
| 6 | 连接／同步 Overleaf |
| 7 | 转投期刊／会议 |
| 8 | 审查论文／准备投稿 |
| 9 | 查看进度／待办 |
| 0 | 项目与设置 |

回复编号或直接说需求；无需输入命令，也无需选择 Skill。
例如：“选 1，我想开始一篇会议论文”或“直接帮我改摘要”。
输入“菜单”可返回这里；目标明确时可直接办理。
本地读写和执行需由已授权的 agent 提供；登录与必要权限由你确认。
