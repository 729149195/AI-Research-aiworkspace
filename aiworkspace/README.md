# AI Research Workspace — 0.3.0

[从仓库首页开始](../README.md)。本目录包含 Python 引擎、13 个可修改 Skills、Idea Evaluation Markdown、可复测代码和文档。论文实例在框架仓库外创建，研究与正式稿件并列。

安装：`python -m pip install -e ./aiworkspace`（仓库根目录、专用虚拟环境）。检查：`rw doctor`。完整合成演示：`rw demo ../new-demo`。

新增 [模板和当前投稿规则](docs/PUBLICATION.md)、[自建 Overleaf](docs/OVERLEAF.md)、[转投迁移](docs/RESUBMISSION.md)，通过 auto-route 自然调用。原生稿件支持 Markdown 和显式绑定的 LaTeX。用户研究内容不在框架升级目标内。

开发和验证见 [CONTRIBUTING](CONTRIBUTING.md)、[DELIVERY](DELIVERY.md)。新功能的证据、失败边界及外部接口原始文档见 [PUBLICATION_SOURCES](docs/PUBLICATION_SOURCES.md)。
