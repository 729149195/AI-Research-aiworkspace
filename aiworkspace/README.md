# AI Workspace 0.4.0

这是框架实现目录。用户从 [自然语言指南](docs/START_WITH_AGENT.md) 或 [菜单](MENU.md) 开始；可以直接对 agent 说“显示菜单”或描述任务。

Agent 请读取 [workspace-guide](research_workspace/assets/skills/workspace-guide/SKILL.md) 和 [操作手册](docs/AGENT_PLAYBOOK.md)。无需让用户手工输入代码、JSON 或 Skill 名称。这里的 Python 命令供 agent 与开发者使用。

14 个 Skills 覆盖菜单、自动沉淀、模板与规则、Overleaf、转投、文献、证据、逻辑方法、写作、图表、同步、审查和 Idea Evaluation。用户研究保持在独立目录，Workspace 与 Manuscript 并列。
